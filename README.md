## Preview locally

1. Extract the ZIP.
2. Open the `siddardha-portfolio-final` folder in VS Code.
3. Open a terminal in that folder and run:

```bash
python -m http.server 8000
```

4. Visit `http://localhost:8000`.

You can also double-click `index.html`, but a local server is better for testing.

## Publish free with GitHub Pages

1. Sign in to https://github.com using the `Siddu-009` account.
2. Create a **Public** repository named exactly `Siddu-009.github.io`.
3. Keep the repository empty when creating it (do not add a README).
4. Extract this ZIP. Open the extracted `siddardha-portfolio-final` folder.
5. Upload the *contents* of this folder to the repository root. `index.html` must be at the root, not inside another folder.
6. In the repository, open **Settings → Pages**.
7. Under **Build and deployment**, choose **Deploy from a branch**.
8. Select branch **main** and folder **/(root)**, then click **Save**.
9. Open the **Actions** tab and wait for the Pages deployment workflow to complete.
10. Visit https://siddu-009.github.io/.

## Publish using Git (alternative)

Run these commands in the extracted project folder:

```bash
git init -b main
git add .
git commit -m "Publish Siddardha portfolio"
git remote add origin https://github.com/Siddu-009/Siddu-009.github.io.git
git push -u origin main
```

If the repository already contains files or an existing remote, inspect it before running these commands; do not overwrite work blindly.

## Update the website later

Edit the relevant HTML/CSS/JS files, then run:

```bash
git add .
git commit -m "Update portfolio"
git push
```

GitHub Pages will redeploy after the push.
